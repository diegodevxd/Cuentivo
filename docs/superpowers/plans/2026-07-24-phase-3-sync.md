# Fase 3: sincronización offline-first Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sincronizar Cuentivo entre Room y Firestore de manera idempotente, segura y tolerante a trabajar sin conexión.

**Architecture:** Room mantiene la lectura de la interfaz y `sync_operations` conserva las escrituras pendientes. Un adaptador Firestore convierte entidades a documentos deterministas y un Worker procesa y vuelve a intentar la cola; la fusión remota no sobrescribe movimientos financieros.

**Tech Stack:** Kotlin, Room, Firebase Authentication, Cloud Firestore Standard, WorkManager, JUnit.

## Global Constraints

- Dinero siempre como `Long` en centavos.
- No registrar PII, saldos completos ni tokens.
- Ventas, pagos y movimientos nunca se sobrescriben ni eliminan durante sincronización.
- Todas las rutas remotas deben estar aisladas por `businessId`.
